# ModelAny

**One API, one key, one bill for the AI models you build with.**

ModelAny is an AI API aggregation platform in development: call language, image and video models through one gateway, manage keys in one console, and keep usage and billing in one place.

- Website: [modelany.com](https://modelany.com/)
- How the API is meant to work: [modelany.com/api](https://modelany.com/api/)
- About: [modelany.com/about](https://modelany.com/about/)

## Status

In active design and development. Not open for sign-ups yet; no waitlist and nothing to buy today.

## This repository

This repository holds the public placeholder site for modelany.com (`site/`, static HTML served by Cloudflare Workers). The product itself is not open source at this time.

ModelAny is built by the CreateKind team. Other products with a similar name are not related to this project.
