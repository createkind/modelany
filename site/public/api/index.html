ModelAny API

One endpoint and one key for language, image and video models. In development.

In development

How the ModelAny API is meant to work

The ModelAny API is planned as a single gateway in front of many AI model providers. You authenticate once with a ModelAny key and choose a model by name in each request. Moving to a different model is meant to be a change of that name, not a new SDK, a new account or a new invoice.

The request format is planned to follow the widely used OpenAI-compatible style for chat and completion calls, so existing client libraries can point at ModelAny by changing the base URL and key.

Planned pieces

  • One key, many models: create and revoke keys in one console; the gateway checks them on every call.
  • Language, image and video: synchronous calls for text, and asynchronous tasks with status and result URLs for image and video generation.
  • Usage logs: per-call and per-task records, so you can see which model and key used what.
  • One balance: prepaid balance and billing records for all models in the same place.

What it is not

ModelAny is not a chat app or a browser extension, and it does not train models. It is an API for developers and teams who build products on top of existing models.

Status

The API is not public yet. There are no sign-ups, no waitlist and nothing to buy today. When it opens, this page will carry the real documentation.
